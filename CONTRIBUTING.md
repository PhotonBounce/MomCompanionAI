# Contributing to Friendai

Thank you for your interest in contributing! Please follow these guidelines:

## How to Contribute
- Fork the repository and create a feature branch.
- Make your changes with clear, descriptive commit messages.
- Ensure all code builds and passes tests (`./gradlew assembleDebug` and `./gradlew test`).
- For UI changes, update screenshots and test on both phone and tablet layouts.
- Submit a pull request with a clear description of your changes.

## Code Style
- Use Kotlin best practices and idiomatic Android patterns.
- Document public classes and methods with KDoc.
- Use meaningful variable and function names.
- Keep UI accessible and follow Material Design guidelines.

## Issues
- Search existing issues before opening a new one.
- Provide clear steps to reproduce bugs.
- Suggest enhancements with a use case and expected benefit.

## Contact
For questions, open an issue or contact the maintainer listed in the README.

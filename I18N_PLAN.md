# Internationalization (i18n) Improvement Plan

## Current State
- English (default) and Russian (values-ru) translations exist for all main UI strings.
- All user-facing text is in strings.xml for both languages.
- No other languages or translation workflow documented.

## Recommendations
- Add support for additional languages (e.g., Spanish, French, German, Chinese) based on user demand.
- Use Android Studio's Translations Editor for efficient string management.
- Document translation workflow in CONTRIBUTOR_GUIDE.md.
- Add a script or checklist for translators to ensure all new strings are covered.
- Consider community-sourced translations with review.
- Add language switcher in Caregiver Settings (optional, for testing).

## Next Steps
1. Survey users/caregivers for most requested languages.
2. Add new values-xx folders and strings.xml for each language.
3. Update CONTRIBUTOR_GUIDE.md with translation instructions.
4. Add translation status to README or project board.

---

This plan ensures the app remains accessible and inclusive as it grows.

# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this app or its backend, please report it privately to the maintainer listed in the README or app settings. Do not disclose security issues publicly until they have been reviewed and patched.

- Email: [add your contact email here]
- Do not use GitHub issues for sensitive security reports.

## Supported Versions

Only the latest release is supported with security updates. Please update to the latest version before reporting issues.

## Security Best Practices

- Do not share your AI backend token or PIN publicly.
- Use a strong, unique PIN for caregiver settings.
- Keep your device and backend server updated with the latest security patches.
- Review PRIVACY_POLICY.md for data handling details.
